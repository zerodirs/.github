# ZeroDirs

**SEO-first. AI-agent native. $0/mo hosting bill. ZeroDirs.**

The SEO-first, AI-agent-ready directory boilerplate built on Astro + Cloudflare.
Launch directory sites that load instantly, rank on Google, and cost $0/mo to run.

- 🌐 Website: [zerodirs.com](https://zerodirs.com)
- 🚀 Live Demo: [demo.zerodirs.com](https://demo.zerodirs.com)

**Why ZeroDirs**
- ⚡ Static-first: content pages ship zero client-side JavaScript
- 💰 Monetization built in: paid submissions, featured listings, click analytics
- 🔍 SEO engine: programmatic pages, internal linking, structured data — all automated
- 🤖 AI-agent native: AGENTS.md + skills — works with Claude Code, Codex, and Gemini
- ☁️ Cloudflare all the way: Workers, D1, R2 — no third-party services to babysit
